SPAN AND DIV TAGS

HTML stands for HyperText Markup Language. It is the absolute backbone of every website on the internet. It uses special commands to tell your web browser how to display text, images, and links. Without HTML, the internet would just be plain text without any structure or design.


Websites are built using various structural pieces. These elements are created using opening and closing marks for paragraphs, headings, and lists. Programmers combine these different blocks to design clean layouts. Knowing how to arrange these pieces correctly is the first step to becoming a great web developer


While HTML creates the structure of a webpage, CSS is used to make it look beautiful. HTML provides the raw text and images, while CSS adds colors, fonts, and spacing. By using structural container boxes and individual word styling, you can change the look of any specific word or section on your website.
